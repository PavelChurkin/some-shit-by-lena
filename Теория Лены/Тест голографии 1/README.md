# Тест голографии 1

Расчётное приложение к [отчёту по issue #14](../отчёт-2026-10-27T16-40-00Z.md).
[Исходная переписка](../Голография/Рефлексия.txt) сохранена отдельно.
Все эксперименты конечны, детерминированы и работают офлайн.

## Запуск и проверка

Из корня репозитория, Python 3.12 или новее; основные расчёты и тесты
используют только стандартную библиотеку:

```bash
python3 "Теория Лены/Тест голографии 1/checks.py" --check --verbose
python3 -m unittest discover -s "Теория Лены/Тест голографии 1" -v
```

`checks.py` без аргументов печатает все 15 групп результатов в JSON;
`--write` обновляет [сохранённые результаты](./results/results.json).
`--check` сверяет их с повторным расчётом, не перезаписывая файл
(допуск для различий libm: относительный 10⁻¹¹, абсолютный 10⁻²⁵).
Пути к данным не зависят от текущего рабочего каталога.
Трассировка выключена по умолчанию и включается через `--verbose`.

Тесты независимо проверяют пределы Рэлея–Джинса и Вина, интеграл Планка,
единицы FIRAS, факториальные моменты фотонного числа, пределы HOM,
контрольные точки IAPWS и численную производную объёма, экранирование,
приведённую массу, определение аномалии g, непрерывность β-спектра,
знаки часовых поправок, площадь горизонта и неединственность модели.
CI повторяет тесты и сверку JSON на Python 3.12 и 3.13 без скачивания данных.

## Что именно сравнивается

В [SOURCES.md](./SOURCES.md) указаны первичные источники, хеши локальных
таблиц, единицы, неопределённости и все выбранные параметры. В JSON поле
`kind` отличает опубликованные данные, эталонные уравнения, иллюстрации
и доказательство недостаточности исходных условий. `False` в полях
`holographic_prediction`, `experimental_residual_test_performed` и подобных
обозначает **отсутствие** такого результата; успешный тест Python его не заменяет.

Таблица `atoms.radii` содержит все Z=1…118, оценки радиусов с экранированием
для Z≤20 и доступные энергии ионизации. `null` не заменяется выдуманной
энергией: в выгрузке NIST для Z=109…118 строк нет. Ковалентный радиус и
характерный радиус водородоподобного электрона имеют разные определения.

## Рисунок (необязательная зависимость)

[Обзор](./results/overview.png) строится из тех же данных. Для перегенерации
в отдельном виртуальном окружении Python 3.12:

```bash
python3.12 -m venv /tmp/holography-plot
/tmp/holography-plot/bin/python -m pip install -r "Теория Лены/Тест голографии 1/requirements-plot.txt"
/tmp/holography-plot/bin/python "Теория Лены/Тест голографии 1/render_figures.py"
```

Верхний левый график содержит настоящие опубликованные остатки FIRAS;
правый нижний — выбранный идеальный HOM-пример, без экспериментальных
отсчётов. Подписи намеренно сохраняют это различие.
