# Тест голографии 2

Офлайн-расчёты к [issue #16](https://github.com/PavelChurkin/some-shit-by-lena/issues/16)
и [отчёту](../отчёт-2026-11-04T12-00-00Z.md). Только стандартная библиотека Python.

```
python3 checks.py            # пересчитать results/results.json
python3 checks.py --check    # сверить с сохранённым результатом
python3 -m unittest discover -s .
```

| Функция | Что считает |
|---|---|
| `horizon_check` | r_s, площадь, евклидов «объём», A/V=3/r_s, энтропия в битах, Mc²=F_P·r_s/2, Λr_s² |
| `merger_check`, `kerr_area`, `sphere_merge_area_loss` | Потеря площади 3D-шаров (20,63%) против роста площади горизонта в ОТО |
| `cascade_check`, `cut_length`, `neck_radius` | Длина набега запаздывания до шага каждого «этажа» и момент, когда она равна радиусу шейки |
| `chirality_check`, `angular_momentum` | Чётностный критерий: знак закрутки и градиент |

Источники входных чисел: CODATA 2018 (G, ħ); Planck 2018 VI (Λ);
Scheel et al. 2009, PRD 79, 024003 (остаток равных масс: M_f=0,95162 M, χ=0,68646);
Abbott et al. 2016, PRL 116, 061102 (GW150914); Isi et al. 2021, PRL 127, 011103
(проверка теоремы о площади на GW150914); Day, Hinch, Lister 1998, PRL 80, 704
(невязкая шейка r=0,7(σ/ρ)^{1/3}τ^{2/3}). Шаги «этажей» каскада и разность скоростей
каналов — **иллюстративные допущения**, а не измерения.
